# /pr-agent commands

Type `/pr-agent` followed by what you want, in plain words. Have Premiere Pro
open with your project loaded first.

## Setup and checks

```
/pr-agent
/pr-agent check you're connected to Premiere
/pr-agent what sequences are in my project?
/pr-agent what .mogrt templates do I have?
/pr-agent save my house style – font Montserrat, colours #000 and #F5E6C8, export to ~/Desktop/Exports
```

## Editing

```
/pr-agent make a rough cut from the clips in my project
/pr-agent remove the silences from my open sequence
/pr-agent make a 9:16 version for Reels
/pr-agent cut this down to 30 seconds
/pr-agent duck the music under my voice
```

## Captions and text

```
/pr-agent add captions
/pr-agent add a hook title in the first 2 seconds that says "..."
```

## Motion graphics

```
/pr-agent add a lower third with my name and "Manila"
/pr-agent add callout words on the key lines
/pr-agent add an end card that says "follow for part 2"
/pr-agent add a slow push-in on every photo
/pr-agent put my logo in the corner
```

Animated titles, lower thirds and end cards need a Motion Graphics Template
(.mogrt). Without one, the agent can still animate clips with keyframes
(push-ins, pans, slides, pops, fades).

## Exporting

```
/pr-agent export for Instagram
/pr-agent export a cover frame from the best moment
/pr-agent export, then write the caption
```

## Several steps in one message

```
/pr-agent remove silences, make it 9:16, add captions and an end card, then export for Reels
```

These are examples, not fixed commands. Ask for anything you'd do in Premiere
in your own words. `/pr-agent` on its own checks the connection, lists your
sequences and templates, then asks what to edit.
